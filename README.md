## Social authentication

Set these server-side environment variables for Google and GitHub OAuth:

```env
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_GOOGLE_CLIENT_ID=...
BETTER_AUTH_GOOGLE_CLIENT_SECRET=...
BETTER_AUTH_GITHUB_CLIENT_ID=...
BETTER_AUTH_GITHUB_CLIENT_SECRET=...
```

Register these callback URLs with the providers:

- Google: `http://localhost:3000/api/auth/callback/google`
- GitHub: `http://localhost:3000/api/auth/callback/github`

For deployment, use the deployed origin in `BETTER_AUTH_URL` and register its callback URLs with the providers. The auth client uses the current site origin, so it does not need a separate localhost URL.
